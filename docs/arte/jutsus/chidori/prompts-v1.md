Modo: imagegen integrado; fundo transparente.

## Mão

Use case: stylized-concept. Asset type: pixel art spritesheet for Village Ninja top-down oblique 2D game. Create Chidori lightning chakra attached to a ninja's palm: EFFECT ONLY, no character or hand drawn. Transparent background. Exactly 8 frames in a perfectly regular 4 columns x 2 rows sheet, landscape 2:1, square equal cells. Same fixed palm anchor at exact center of each cell, identical scale between frames, generous transparent margins. Sharp pixel art, stepped contours, limited palette white core, pale blue, cyan, dark blue edge; no fuzzy glow. Irregular branched jagged electricity radiating from a SMALL dense white irregular nucleus; must look like dangerous crackling lightning, NOT a smooth round Rasengan sphere, NOT a star, flower or snowflake. Frame order row-major: 1 a few small sparks forming at center; 2 gathering brighter strands; 3 full crackling compact white nucleus with asymmetric forks; frames 4,5,6 same maximum size with distinct flickering fork shapes for active loop; 7 breaking into short fading branches; 8 a few final small residual sparks. Keep all frames visibly distinct, center perfectly registered, no global background, no grid lines, no labels, no lettering, no shadows, no checkerboard painted in image. Designed to display about 28-36 game pixels across at full active stage.
